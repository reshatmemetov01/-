# Telegram-бот: воронка продаж курса по ПДД

Бот ведёт человека от первого касания до заявки или оплаты онлайн-курса подготовки
к теоретическому экзамену ПДД в ГИБДД.

## Как устроена воронка

```
/start (метка источника из ссылки)
   │
   ▼
Сегментация: «готовлюсь к экзамену» / «пересдача» / «хочу освежить»
   │
   ▼
Лид-магнит: бесплатный мини-тест из 10 вопросов по ПДД
   │   (разбор каждого ответа со ссылкой на пункт ПДД)
   ▼
Результат «сдали бы вы экзамен?» + подарок: чек-лист «10 ловушек экзамена»
   │
   ▼
Оффер под сегмент + 3 тарифа (990 / 2490 / 4990 ₽)
   │
   ├─► Оплата прямо в Telegram (если подключена платёжка) → доступ к курсу
   └─► Заявка: имя + телефон → уведомление менеджеру
```

**Дожимающая цепочка** — тем, кто не оставил заявку и не оплатил:

| Когда              | Сообщение                                                        |
|--------------------|------------------------------------------------------------------|
| через 1 час        | Не прошёл тест → зовём в тест. Прошёл → мотивация к подготовке   |
| ещё через 1 день   | История ученицы (кейс)                                            |
| ещё через 2 дня    | Персональная скидка 20% на 48 часов                               |
| ещё через 4 дня    | Последнее напоминание + кнопка «Написать менеджеру»              |

Цепочка останавливается сразу после заявки или оплаты, переживает перезапуск
бота (расписание хранится в базе), а заблокировавших бота пользователей помечает
и больше им не пишет.

## Команды администратора

Доступны только пользователям из `ADMIN_IDS`:

- `/stats` — воронка по этапам с конверсией и статистика по источникам трафика;
- `/export` — выгрузка заявок и оплат в CSV (открывается в Excel);
- `/broadcast текст` — рассылка всем; или ответьте `/broadcast` на любое сообщение
  (с фото, видео, кнопками), чтобы разослать его копию.

Каждая заявка и оплата сразу приходит админам карточкой: имя, телефон, цель,
результат теста, тариф, источник.

## Метки источников (UTM)

Давайте в разные каналы разные ссылки — в `/stats` будет видно, откуда приходят заявки:

```
https://t.me/ИМЯ_БОТА?start=vk_ads
https://t.me/ИМЯ_БОТА?start=instagram
https://t.me/ИМЯ_БОТА?start=avtoshkola_partner
```

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID (например, у @userinfobot).
3. Настройте окружение:

```bash
cp .env.example .env      # и впишите BOT_TOKEN, ADMIN_IDS
pip install -r requirements.txt
python -m bot
```

Или через Docker:

```bash
docker build -t pdd-bot .
docker run -d --restart=always --env-file .env -v pdd_data:/data pdd-bot
```

### Приём оплаты в Telegram (необязательно)

В @BotFather → ваш бот → Payments подключите провайдера (ЮKassa и др.) и
впишите токен в `PAYMENT_PROVIDER_TOKEN`. Без него кнопки тарифов ведут на
форму заявки. Ссылку на курс, которую клиент получит после оплаты, укажите в `ACCESS_LINK`.

### Быстрая проверка дожимающей цепочки

Поставьте `FOLLOWUP_DELAY_SCALE=0.0003` — все задержки сожмутся, и цепочка
пройдёт примерно за 3–4 минуты (бот проверяет очередь раз в 20 секунд).

## Как поменять тексты, цены и вопросы

Всё содержимое воронки — в одном файле [`bot/content.py`](bot/content.py):
приветствие, сегменты, вопросы теста, чек-лист, оффер, тарифы и цены,
размер скидки, тексты и задержки дожимающих сообщений.

> Тексты, цены, кейс ученицы и описание тарифов — примеры. Замените их
> на реальные данные вашего продукта перед запуском.

## Структура

```
bot/
  __main__.py      точка входа (python -m bot)
  config.py        настройки из .env
  content.py       тексты, тест, тарифы, дожимающая цепочка
  db.py            SQLite: пользователи и этапы воронки
  followups.py     фоновая отправка дожимающих сообщений
  keyboards.py     кнопки
  notify.py        уведомления админам
  handlers/        start, quiz, offer (тарифы и оплата), lead (заявка), admin, fallback
tests/test_flow.py сквозной тест всей воронки без доступа к Telegram
```

Тесты: `python tests/test_flow.py` (или `pytest`).
