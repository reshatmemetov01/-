# Бот «Разборы ПДД» — Эльдар

Telegram-бот, который продаёт доступ к закрытому каналу с видео-разборами всех 40 билетов ПДД.

## Как идёт клиент

```
Описание бота («Что умеет этот бот?») → /start
   │
   ▼
Приветствие + обязательная подписка на канал (бот проверяет подписку)
   │
   ▼
«Рад тебя видеть» — кто такой Эльдар и что он сделал → [⭐ ПОКАЗАТЬ]
   │
   ▼
Видео-показ канала + «Вот как это выглядит» → [🎁 Бесплатные разборы] [👑 ПОЛУЧИТЬ ДОСТУП]
   │
   ▼
Оффер: 1490 ₽, доступ навсегда → [💳 Оплатить по СБП] [🎟 Ввести промокод]
   │
   ▼
После оплаты бот сам присылает одноразовую ссылку в закрытый канал
```

**Меню внизу:** 👑 Видео разборы · 📝 Тренировка · 💬 Отзывы · ❓ Частые вопросы · ℹ️ Информация.
У админа дополнительно — 🛠 Админка.

- **Видео разборы** — купившим даёт ссылку в канал, остальным показывает оффер.
- **Тренировка** — экзамен из 20 случайных вопросов. 3 ошибки — экзамен окончен, и бот
  предлагает купить доступ. Сдал — короткая похвала.
- **Отзывы / Частые вопросы / Информация** — пока «скоро появится», тексты добавим позже.

## Дожимающие сообщения

Отправляются автоматически и **только тем, кто не купил** — раз в 6 часов, каждый раз новое
сообщение со своим доводом (почему зубрёжка не работает, чат с поддержкой, бесплатный разбор,
проверь себя экзаменом и т.д.). Повторов нет.

- Не подписан на канал → первым приходит просьба подписаться.
- Открывал оплату, но не оплатил → один раз приходит «вижу, ты открыл оплату».
- Ночью (23:00–9:00 по Москве) не пишем — сообщение переносится на 9:00.
- После покупки рассылка сразу прекращается. Всего ~20 сообщений (≈5 дней), потом бот замолкает,
  чтобы не превращаться в спам.

Тексты, порядок и интервал — в `bot/content.py` (`FOLLOWUP_MESSAGES`, `FOLLOWUP_ORDER`, `FOLLOWUP_INTERVAL`).

## Админка (кнопка «🛠 Админка» или /admin)

- **📊 Статистика** за сегодня / 7 дней / всё время: зашли → подписались → смотрели показ →
  дошли до оплаты → нажали «оплатить» → купили, с процентами, выручка, результаты экзамена,
  источники трафика.
- **👥 Пользователи** — списки прямо в боте: «дошли до оплаты, но не купили», «купили», «все».
- **💳 Ждут подтверждения** — чеки, которые прислали клиенты (временная оплата по СБП).
  Кнопки «✅ Подтвердить» / «❌ Отклонить». После подтверждения бот сам выдаёт ссылку.
- **📣 Рассылка** — всем / кто не купил / кто купил. Можно текст, фото, видео — что угодно.
- **🎁 Выдать доступ** — вручную по ID, @username или пересланному сообщению.
- **🎬 Видео в воронке** — загрузи видео-показ канала и бесплатные разборы прямо в бота.

О каждой покупке приходит уведомление.

## Оплата

Сейчас — **временная оплата по СБП**: клиент видит реквизиты из `PAYMENT_DETAILS`,
платит, присылает чек, ты подтверждаешь кнопкой. Когда зарегистрируешь Platega,
добавим автоматическую оплату — кнопка встанет в оффер рядом с остальными (`bot/keyboards.py → offer`).

## Запуск

1. Создай бота у @BotFather, получи токен. Там же загрузи картинку-обложку:
   *Edit Bot → Edit Description Picture*. Текст описания бот поставит сам при запуске.
2. Добавь бота **админом** в публичный канал и в закрытый канал с разборами.
3. `cp .env.example .env` и заполни.
4. Запусти:

```bash
pip install -r requirements.txt
python -m bot
```

Или в Docker:

```bash
docker build -t pdd-bot .
docker run -d --restart=always --env-file .env -v pdd_db:/db pdd-bot
```

5. Открой бота → «🛠 Админка» → «🎬 Видео в воронке» и загрузи видео.

## Запуск на VPS (Ubuntu/Debian)

Выполняй по шагам на сервере:

```bash
# 1. Python и git
sudo apt update && sudo apt install -y python3 python3-venv git

# 2. Отдельный пользователь для бота и папка
sudo useradd -r -m -d /opt/pdd-bot pddbot
sudo -u pddbot git clone https://github.com/reshatmemetov01/-.git /opt/pdd-bot/app
# (или скопируй файлы проекта в /opt/pdd-bot любым способом)
sudo -u pddbot bash -c 'cp -r /opt/pdd-bot/app/. /opt/pdd-bot/ && rm -rf /opt/pdd-bot/app'

# 3. Зависимости
sudo -u pddbot python3 -m venv /opt/pdd-bot/venv
sudo -u pddbot /opt/pdd-bot/venv/bin/pip install -r /opt/pdd-bot/requirements.txt

# 4. Настройки: скопируй пример и заполни (токен, ADMIN_IDS, каналы, реквизиты)
sudo -u pddbot cp /opt/pdd-bot/.env.example /opt/pdd-bot/.env
sudo -u pddbot nano /opt/pdd-bot/.env

# 5. Автозапуск
sudo cp /opt/pdd-bot/deploy/pdd-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now pdd-bot
```

Полезные команды:

```bash
sudo systemctl status pdd-bot      # работает ли бот
sudo journalctl -u pdd-bot -f      # логи в реальном времени
sudo systemctl restart pdd-bot     # перезапуск (после изменения .env или кода)
```

> Бот должен быть запущен **только в одном месте**. Если он работает на VPS,
> не запускай его одновременно на компьютере — Telegram будет выдавать ошибку конфликта.

База (`pdd_bot.db`) лежит в `/opt/pdd-bot` — её стоит иногда копировать себе как резервную копию.
