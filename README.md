# Бот «Разборы ПДД» — Эльдар

Telegram-бот, который продаёт доступ к закрытой группе (видео-разборы всех 40 билетов ПДД + чат с учениками).

## Как идёт клиент

```
Описание бота («Что умеет этот бот?») → /start
   │
   ▼
Приветствие + ссылка на канал по желанию: [📢 Подписаться] [➡️ Продолжить]
   │
   ▼
«Рад тебя видеть» — кто такой Эльдар и что он сделал → [⭐ ПОКАЗАТЬ]
   │
   ▼
Видео-показ канала + «Вот как это выглядит» → [👑 ПОЛУЧИТЬ ДОСТУП]
   │
   ▼
Оффер: 1490 ₽, доступ навсегда → [💳 Оплатить по СБП] [🎟 Ввести промокод] [💬 Поддержка]
   │
   ▼
После оплаты бот сам присылает одноразовую ссылку в закрытую группу (разборы + чат)
```

**Меню внизу:** 👑 Видеоразборы · 📝 Тренировка · 👥 Отзывы · ❓ Частые вопросы · ℹ️ Информация · 💬 Поддержка.
У админа дополнительно — 🛠 Админка.

- **Видео разборы** — купившим даёт ссылку в канал, остальным показывает оффер.
- **Тренировка** — экзамен из 20 случайных вопросов. 3 ошибки — экзамен окончен, и бот
  предлагает купить доступ. Сдал — короткая похвала.
- **Частые вопросы** — ответы на типичные вопросы.
- **Информация** — об Эльдаре и боте + ссылки на пользовательское соглашение и политику конфиденциальности.
- **Отзывы** — отзывы учеников по 5 на страницу; добавляются и удаляются в админке.
- У каждого раздела нижнего меню есть кнопка «⬅️ Назад» — сообщение превращается в «Добро пожаловать! Выбери категорию».
- **Поддержка** — кнопка, ведущая в личку Эльдару (`MANAGER_USERNAME`).

## Дожимающие сообщения

Отправляются автоматически и **только тем, кто не купил** — раз в 6 часов, каждый раз новое
сообщение со своим доводом (почему зубрёжка не работает, чат с поддержкой,
проверь себя экзаменом и т.д.). Повторов нет.

- Не подписан на канал → первым приходит просьба подписаться.
- Открывал оплату, но не оплатил → один раз приходит «вижу, ты открыл оплату».
- Ночью (23:00–9:00 по Москве) не пишем — сообщение переносится на 9:00.
- После покупки рассылка сразу прекращается. Всего ~20 сообщений (≈5 дней), потом бот замолкает,
  чтобы не превращаться в спам.

Тексты, порядок и интервал — в `bot/content.py` (`FOLLOWUP_MESSAGES`, `FOLLOWUP_ORDER`, `FOLLOWUP_INTERVAL`).

## Админка (кнопка «🛠 Админка» или /admin)

- **📊 Статистика** за сегодня / 7 дней / всё время: зашли → подписались → смотрели показ →
  дошли до оплаты → нажали «оплатить» → купили, с процентами, выручка, результаты экзамена,
  источники трафика.
- **👥 Пользователи** — списки прямо в боте: «дошли до оплаты, но не купили», «купили», «все».
- **💳 Ждут подтверждения** — чеки, которые прислали клиенты (временная оплата по СБП).
  Кнопки «✅ Подтвердить» / «❌ Отклонить». После подтверждения бот сам выдаёт ссылку.
- **📣 Рассылка** — всем / кто не купил / кто купил. Можно текст, фото, видео — что угодно.
- **🎁 Выдать доступ** — вручную по ID, @username или пересланному сообщению.
- **🎬 Видео в воронке** — загрузи видео-показ канала прямо в бота.
- **⭐ Отзывы** — добавить отзыв (текст + имя или @username автора) и удалить.

О каждой покупке приходит уведомление.

## Оплата

Кнопка «💳 Оплатить по СБП» ведёт на многоразовую ссылку Paydex из `PAYMENT_URL`. Под ней —
«✅ Я оплатил»: клиент присылает скрин чека, админу приходит уведомление с кнопками
«Подтвердить / Отклонить», после подтверждения бот сам выдаёт ссылку в группу.

## Запуск

1. Создай бота у @BotFather, получи токен. Там же загрузи картинку-обложку:
   *Edit Bot → Edit Description Picture*. Текст описания бот поставит сам при запуске.
2. `cp .env.example .env` и заполни (достаточно `BOT_TOKEN`, `ADMIN_IDS` и реквизитов).
3. Закрытая группа подключается без правки файлов: добавь бота **администратором** (с правом
   «Пригласительные ссылки») в группу с разборами. Ссылку на канал для приветствия укажи в
   `CHANNEL_URL` (или добавь бота админом и в канал).
   Бот сам напишет тебе «Меня сделали админом в …, что это за чат?» — нажми нужную кнопку.
   Текущие настройки — «🛠 Админка → 🔗 Каналы и группа».
4. Запусти:

```bash
pip install -r requirements.txt
python -m bot
```

Или в Docker:

```bash
docker build -t pdd-bot .
docker run -d --restart=always --env-file .env -v pdd_db:/db pdd-bot
```

5. Открой бота → «🛠 Админка» → «🎬 Видео в воронке» и загрузи видео.

## Запуск на VPS (Ubuntu 22.04+ / Debian 12+)

**Установка — одна команда** (подключись к серверу по SSH и вставь):

```bash
curl -fsSL https://raw.githubusercontent.com/reshatmemetov01/-/claude/epic-fermat-yuhupj/deploy/install.sh | sudo bash
```

Скрипт сам поставит Python, скачает бота, спросит токен и остальные настройки
(Enter — оставить предложенное значение) и включит автозапуск: бот стартует вместе с
сервером и перезапускается при сбое.

**Обновление после изменений** — тоже одна команда:

```bash
sudo bash /opt/pdd-bot/deploy/update.sh
```

Полезное:

```bash
sudo systemctl status pdd-bot      # работает ли бот
sudo journalctl -u pdd-bot -f      # логи в реальном времени (выход — Ctrl+C)
sudo nano /opt/pdd-bot/.env        # поменять настройки, потом: sudo systemctl restart pdd-bot
```

> Бот должен быть запущен **только в одном месте** — иначе Telegram выдаёт ошибку конфликта.

База (`/opt/pdd-bot/pdd_bot.db`) — пользователи, статистика, оплаты. Её стоит иногда
копировать себе как резервную копию.

## База вопросов

Исходники билетов лежат в `raw/`: `biletN.txt` (вопросы, ответы, пояснения) и `kartinkiN/` (картинки
билета N). Чтобы добавить билеты:

1. Загрузи `biletN.txt` и папку `kartinkiN` в `raw/` (на GitHub: Add file → Upload files).
2. Выполни `python tools/import_tickets.py` — он проверит билеты (20 вопросов, ответы, картинки)
   и пересоберёт `data/questions.json` и `data/images/`. Билет без картинок пропускается с предупреждением.
3. Обнови бота на сервере (`update.sh`).

**Тренировка** в боте:
- 🎫 **По билетам** — 20 вопросов билета по порядку с пояснениями, в конце итог.
- 🎯 **Экзамен** — 20 случайных вопросов, на 3-й ошибке экзамен заканчивается.

Ссылка `https://t.me/pdd_eldarkhan_bot?start=ticket_5` сразу запускает тест по 5-му билету —
её удобно ставить под видео-разбором билета в группе («Пройти тест»).
