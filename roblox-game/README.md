# 🔥 Пол — это лава! (Roblox obby)

Паркур в Roblox: пол — это лава, а игрок прыгает по мебели, тарелкам, камням и облакам.
**Карта строится сама из кода** — руками ничего строить не нужно.

## Что внутри

**Карта — 50 этапов в 5 зонах (змейкой, с подъёмом вверх):**

| Зона | Этапы | Что там |
|---|---|---|
| 🛋 Гостиная | 1–10 | столы, диваны, табуретки, стопки книг, книжные шкафы с лестницами, ковёр с полосами лавы, свечи |
| 🍳 Кухня | 11–20 | тарелки на стаканах, сковородки, сыр, конвейер, «блендер» (крутилка), тостер-батут, холодильник |
| 🪨 Лавовые пещеры | 21–30 | камни, мосты с **падающими сталактитами**, рассыпающиеся камни, сталагмиты, вращающиеся диски |
| 🌋 Жерло вулкана | 31–40 | базальтовые колонны, **волна лавы поднимается каждые ~20 сек** — прячься на островок! |
| ☁️ Небо | 41–50 | облака, батуты, радужные канаты, исчезающие облачка, финиш с кубком 🏆 |

Препятствия: прыжки, полосы лавы (в том числе мигающие), движущиеся платформы, исчезающие платформы,
крутилки-убийцы, лестницы-фермы, батуты, канаты, столбики, конвейеры, сталактиты, вращающиеся диски.
Сложность плавно растёт от 1 до 50 этапа.

**Пасхалки:**
- 🦆 5 секретных уточек (на табличке в лобби, у этапа 7, в двух тайных комнатах, у этапа 45).
  Все 5 → +1000 монет, след «Золотая утка» и значок 🦆 над головой.
- 🔥 Этап 23: «лавопад» сбоку — через него можно пройти, за ним секретная комната с сундуком.
- ⚠️ Этап 28: табличка «НЕ ПРЫГАЙ СЮДА». Внизу тайная пещера с сундуком и телепортом назад.
- 🔴 Этап 15: кнопка «НЕ НАЖИМАЙ» — превращает лаву в воду для всего сервера на 12 секунд.
- 👑 VIP-комната в лобби (дверь пропускает только VIP).

**Чтобы игроки возвращались:**
- сохранение прогресса, монет и следов;
- ежедневная награда (7 дней подряд, награда растёт);
- 🎁 подарок каждые 5 минут игры;
- 🔁 перерождения: после финиша начинаешь заново, но с множителем монет +50% навсегда;
- следы за монеты (Искра, Океан, Токсик, Конфета, Галактика, Радуга) и секретные следы;
- монетки на трассе, таблица лидеров в лобби, сообщения всем «X прошёл игру!».

**Покупки за Robux (сначала их нужно настроить, см. ниже):**
- Game Pass: ⚡ Скорость, 🪙 x2 монеты, 👑 VIP.
- Developer Products: ⏭ Пропуск этапа, 💰 500 монет, 🌊 Лава → вода для всего сервера.

## Как запустить (примерно 15 минут)

1. Скачай **Roblox Studio** с сайта roblox.com (кнопка «Create» → «Start Creating») и войди в аккаунт.
2. Нажми **New** → шаблон **Baseplate**. Серая плита из шаблона удалится сама.
3. Включи окна: вкладка **View** → **Explorer** и **Properties**.
4. Создай 4 скрипта. Наведи на папку в Explorer, нажми **⊕** и выбери тип:

   | Где (папка в Explorer) | Тип | Имя (ровно так!) | Скопировать код из файла |
   |---|---|---|---|
   | ReplicatedStorage | ModuleScript | `LavaConfig` | `src/shared/LavaConfig.luau` |
   | ServerScriptService | ModuleScript | `MapBuilder` | `src/server/MapBuilder.luau` |
   | ServerScriptService | Script | `GameServer` | `src/server/GameServer.server.luau` |
   | StarterPlayer → StarterPlayerScripts | LocalScript | `LavaClient` | `src/client/LavaClient.client.luau` |

   Переименовать — двойной клик по имени. Открой скрипт двойным кликом, удали всё, что там
   написано, и вставь код из файла целиком.
5. Нажми **▶ Play**. Карта построится за пару секунд, и ты появишься в лобби.
6. Сохрани: **File → Publish to Roblox** (придумай название и описание).
7. Чтобы прогресс сохранялся и в Studio: **Home → Game Settings → Security** →
   включи **Enable Studio Access to API Services**. На опубликованной игре это работает само.
8. Сделай игру публичной: на **create.roblox.com** → твоя игра → **Privacy: Public**.

> Если пользуешься **Rojo**: `rojo serve` в папке `roblox-game`, затем подключись плагином Rojo в Studio.

## Как настроить заработок 💰

1. Открой **create.roblox.com** → **Creations** → твоя игра → **Monetization**.
2. **Passes** → создай 3 Game Pass'а (картинка + название + цена). Советую такие цены:
   - ⚡ Скорость — 99 R$
   - 🪙 x2 монеты — 149 R$
   - 👑 VIP — 299 R$
3. **Developer Products** → создай 3 продукта:
   - ⏭ Пропуск этапа — 15–25 R$ (это главный источник денег в obby!)
   - 💰 500 монет — 49 R$
   - 🌊 Лава → вода — 39 R$
4. Скопируй ID каждого (цифры) и вставь в `LavaConfig` вместо нулей:
   ```lua
   Config.GamePasses = { Speed = 123456, DoubleCoins = 234567, VIP = 345678 }
   Config.Products = { SkipStage = 111111, Coins500 = 222222, LavaToWater = 333333 }
   ```
5. Опубликуй игру заново (**File → Publish to Roblox**).

**Бейджи** (по желанию): создай их в разделе **Badges** и вставь ID в `Config.Badges`.

### Как вывести Robux в реальные деньги
Через **DevEx**: нужно минимум **30 000 заработанных Robux**, возраст 13+, подтверждённая почта
и проверка личности. ⚠️ Выплаты DevEx идут не во все страны — **проверь заранее на сайте Roblox,
доступны ли они в твоей стране**. Если нет — заработанные Robux останутся на аккаунте.

### Как привести игроков
- Красивая **иконка** и 3–5 **скриншотов** (сделай их на 23-м этапе у лавопада и на финише).
- Название с ключевыми словами: *«Пол — это лава! 🔥 Obby»* / *«Floor is Lava Obby»*.
- Сними короткие ролики для TikTok/Shorts: «нашёл секретную комнату», «НЕ ПРЫГАЙ СЮДА».
- Позже можно запустить рекламу **Sponsored Experiences** (за Robux).
- Обновляй игру: новые этапы и зоны = игроки возвращаются.

## Как менять игру

Всё основное — в `LavaConfig`:
- `MAP_SEED` — поменяй число, и карта перестроится по-другому;
- `TOTAL_STAGES` — количество этапов (кратно 10: каждые 10 этапов — новая зона);
- награды, цены следов, время подарков, длительность «лава → вода» и т.д.

Хочешь украсить вручную? Нажми **Play**, затем во время игры в Explorer найди `Workspace › LavaMap`,
скопируй (Ctrl+C), останови игру, вставь (Ctrl+V) в Workspace. Теперь можно двигать и раскрашивать
блоки, добавлять модели из **Toolbox**. Но тогда в `GameServer` нужно убрать постройку карты —
напиши, помогу.
